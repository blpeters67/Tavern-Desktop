Tavern Desktop 0.1.2 adds a title-bar update button. Updates download in the background from this repository; click **Restart & update** when ready. Restarting ends active calls. Logins and settings are preserved.

Includes the navy-and-gold Tavern title bar, the screen-picker permission fix, and Help → Check Camera and Microphone.

Install this version manually once if you have 0.1.0 or 0.1.1. Later updates use the in-app button.

The installer is unsigned. The reported in-call camera/microphone problem is still awaiting live-session confirmation; local device access and WebRTC transport checks pass.
